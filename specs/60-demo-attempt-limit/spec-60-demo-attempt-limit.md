# Spec 60: Demo Attempt-Limit Prompt

- **Related issue:** [#191](https://github.com/whyi/WA-contested-divorce-without-children-mediation-to-end/issues/191)
- **Amends:** [Spec 57](../57-demo-counteroffer-requirement/spec-57-demo-counteroffer-requirement.md) and [Spec 58](../58-demo-offer-notes/spec-58-demo-offer-notes.md).

Show Next below a current counteroffer in both demos, including at the tier's final attempt. Until a supported file is saved or the notes contain at least 100 trimmed Unicode characters, Next is disabled. At the final attempt, valid details make Next clickable but visually muted. Clicking it opens a tier-specific limit dialog with Upgrade and Cancel. Cancel dismisses it; Upgrade displays "It's the end of this demo!" without starting another attempt or purchasing anything.

Before the limit, valid details advance the Essential demo as before. Past attempts remain read-only. This preview does not change real-account billing or entitlements.
