# Spec 57: Required Demo Counteroffer Details

- **Related issue:** [#183](https://github.com/whyi/WA-contested-divorce-without-children-mediation-to-end/issues/183)
- **Amends:** [Spec 54](../54-demo-counteroffer-visibility/spec-54-demo-counteroffer-visibility.md), for counteroffer continuation.

For both demo identities, a counteroffer must include non-whitespace notes or a successfully stored attachment before Next is enabled and before an attempt can advance. An invalid, failed, or still-pending file upload does not qualify. Previously saved files and notes remain eligible when returning to the same current attempt. The case and attempt associated with a file must match the one being viewed.

The Free demo remains limited to one attempt; satisfying this requirement does not grant another attempt. Rejection, acceptance, historical read-only views, and authenticated case behavior remain unchanged.
