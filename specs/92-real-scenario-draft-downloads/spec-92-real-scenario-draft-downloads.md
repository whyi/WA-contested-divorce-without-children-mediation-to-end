# Spec 92: Real scenario Word and Excel draft downloads

This additive specification amends specs 80, 81 and 90. Prior specifications
remain unchanged.

- Preserve the demo's two download buttons and action layout directly below
  the scenario ideas: **Download CR 2A Word draft** and **Download property
  schedule Excel**. Remove only the fictional/sample wording for real cases.
- A selected available scenario enables both buttons. Incomplete date balances,
  editing/saving and an in-flight download disable downloads. Never export
  fictional demo data or treat missing amounts as zero.
- Export server-saved case values, the selected start/division dates and the
  selected 55%, 50% or 45% share of combined net change. Preserve starting
  balances as baselines and match the displayed scenario calculation.
- Word reuses the existing unsigned CR 2A proposal template and disclosures,
  followed by the scenario summary and both saved balance sheets. Excel includes
  the original dated balances, selected-scenario summary and disclosures.
  Do not infer community/separate legal classifications. Missing party names
  and caption details remain clearly marked for review and completion.
- Authorize the case owner, verify the saved revision, and use the viewed
  attempt's frozen profile for historical or finalized attempts. Reject stale
  revisions, unavailable dates/attempts and incomplete balances explicitly.
- These are **draft** downloads, like the demo's draft buttons. They neither
  finalize nor snapshot an attempt, consume credits, or deliver a proposal.
  Existing final-download finalization rules remain unchanged.
- Surface generation failures with retryable controls and unchanged user work.
  Verify both actual download events/filenames and readable Word/Excel contents,
  all three allocation shares, authorization, failures and frozen snapshots.
