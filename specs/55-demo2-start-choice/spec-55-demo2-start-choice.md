# Spec 55: Demo 2 Preparation Choice

- **Related issue:** [#179](https://github.com/whyi/WA-contested-divorce-without-children-mediation-to-end/issues/179)
- **Amends:** [Spec 44](../44-single-case-demo-flow/spec-44-single-case-demo-flow.md), FR-44-01, FR-44-02, FR-44-07 and acceptance criterion 2.

A fresh Demo 2 starts with the same preparation-path choice as Demo 1 rather than implicitly creating an Essential sample case. Choosing documents or the guided path creates its one browser-local case. Essential remains limited to three attempts.

Re-entering either demo with an existing case resumes that case without resetting or replacing its data. A saved Essential sample case and its attempt history remain available. Direct case URLs continue to open the saved case, while entry URLs without a case ID and legacy Demo 2 entry routes lead to the start flow. Browser storage errors remain visible; no real-account data is changed.
